We are building a website called ChoirTrends.com. The site is designed to be used by Choral Directors, primarily at the secondary/High School level but potentially collegiate and primary/middle school level.
Choral Directors will engage in a participatory manner, uploading their concert program to gain permission to see aggregated data from other choir directors during the same period. Initially, there will be three aggregation periods labeled ”All”, “Spring Programs” and “Winter Programs”, although there is potential for other categories e.g. “Cabaret Programs”, “Madrigal Dinners”, “Senior Recitals”.
The site will be created on the Laravel 12 framework, using the current compatible versions of Livewire, Flux, and Filament. Spatie honeypot will be used to protect the login form. The site will be deployed on Laravel Vapor and hosted on AWS Lambda using MySql database.  The site will be maintained on GitHub with actions to run pint, phpstan, and pest tests. Updates to GitHub staging branch will trigger deployments to Vapor staging environment.  Updates to GitHub:main will trigger deployments to Vapor production environment.   
The upload process will allow for uploads of either pdfs or photos of the user’s concert program. Once uploaded, a Claude-driven analysis will initially identify and isolate the elements of the concert program. Once identified, these items will be displayed to the user for correction and approval. Only after approval will the elements be stored in the database.
Following approval, Claude will then search the internet to find and store publicly available relevant additional data to enrich the analysis. This enrichment will include data about the individual songs in the concert program, the artists (composers, arrangers, performers, etc.), available YouTube and other public references, musical period references, and program notes, as well as relevant background material on the user’s professional experience.
